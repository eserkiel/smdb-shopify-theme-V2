# GTA 6 caption and hashtags

## Input
What the clip shows, the platform, the language, and whether it is sponsored.

## Caption
- 1–2 short lines. The first line carries the hook or payoff, because it is what shows before "more".
- End with a question or call to action that invites comments ("Which detail did you spot first? 👇").
- 1–3 emojis that fit (🌴🔥🚓); don't overdo it.
- If the video is sponsored, start with the required label ("Werbung" or "Anzeige" in Germany, "#ad" elsewhere).
- YouTube (long-form): add a 2–3 sentence description and, if useful, chapters.

## Hashtags
- 5–8 in total: 2–3 broad (#Gaming #PS5), 3–5 specific (#GTA6 #GTAVI #ViceCity #GrandTheftAuto6 #RockstarGames).
- Add one or two that fit the topic (#GTA6Trailer #GTA6Gameplay #GTA6EasterEggs).
- No misleading tags (#GTA6Leak for non-leak content) and no unrelated trending tags.
- Shorts: include #Shorts.

## Output
The caption ready to paste, then the hashtag line. Optionally one alternative caption in a different tone.
